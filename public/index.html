Custom Architecture & README Documentation

1. Custom Application Architecture

Pulse is designed around modern socket streaming paradigms without relying on standard pre-made channel UI templates:

  • Server Authorization: In-memory and database user checks ensure message frames only route to authorized room subscribers.
  • Lossless Reconnection: Sequence IDs (`last_seen_id`) prevent dropping frame packets during dropped connections.
  • Custom Aesthetic: Nordic Slate color theme with custom Amber/Teal gradients and pill-shaped responsive bubbles.

2. Schema Design

-- Users Table
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  username VARCHAR(50) UNIQUE NOT NULL,
  avatar_url TEXT NOT NULL,
  is_online BOOLEAN DEFAULT false
);

-- Hubs / Rooms Table
CREATE TABLE rooms (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(100) NOT NULL,
  type VARCHAR(10) CHECK (type IN ('public', 'private', 'dm'))
);

-- Room Members Table
CREATE TABLE room_members (
  room_id UUID REFERENCES rooms(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  PRIMARY KEY (room_id, user_id)
);

-- Messages Table
CREATE TABLE messages (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  room_id UUID REFERENCES rooms(id) ON DELETE CASCADE,
  sender_id UUID REFERENCES users(id) ON DELETE CASCADE,
  content TEXT,
  attachment_url TEXT,
  is_edited BOOLEAN DEFAULT false
);
