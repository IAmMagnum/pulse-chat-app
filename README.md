# Pulse — Next-Gen Real-Time Workspace


Pulse is a low-latency real-time chat application featuring public group hubs, encrypted direct messaging, instant media uploads, typing indicators, and user presence synchronization built using Node.js Express and native WebSockets.


---


## 1. How to Set Up & Run the Project Locally


### Prerequisites
- Node.js (v18 or higher)
- npm or yarn


### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/pulse-chat-app.git
   cd pulse-chat-app
```
